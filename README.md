# Linear Regression from Scratch

A linear regression model implemented from scratch using gradient descent and NumPy.

## Features

* Linear regression
* Gradient descent
* Mean Squared Error
* Early stopping
* NumPy vectorization
* Loop-based and optimized implementations

## Files

* `Linear_regression.py` — basic loop-based implementation
* `Linear_regression_optimized.py` — NumPy-vectorized implementation
* `demo.ipynb` — testing and demonstration
* `Boston House Price Data.csv` — dataset

## Goal

The goal of this project is to understand how linear regression and gradient descent work internally without using a pre-built regression algorithm.
